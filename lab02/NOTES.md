## Локальные состояния Git

Рабочая папка - файлы на диске, которые я редактирую; git видит изменения, но не сохраняет их.

Индекс (staging area) - промежуточная область, куда я добавляю изменения через git add. Это черновик будущего коммита.

Коммит - зафиксированный снимок индекса в истории. У него есть хеш, автор, дата и сообщение.

## Git и GitHub

Git - распределенная система контроля версий, работает локально на компьютере.

GitHub - облачный сервис для хранения Git-репозиториев и совместной работы.

Git - инструмент, GitHub - платформа.

## Использованные команды

git status-Показывает состояние: на какой я ветке, какие файлы изменены, какие в индексе, какие не отслеживаются, синхронизирован ли я с удаленным репозиторием.

git diff-Сравнивает рабочую папку с индексом - что изменено, но еще не добавлено через git add.

git diff --staged-Сравнивает индекс с последним коммитом - что именно попадет в следующий коммит.

## Ветки

Ветка-Подвижный указатель на коммит. Позволяет вести параллельную разработку, не затрагивая основную линию.

Указатель текущей ветки автоматически сдвигается на новый коммит. Другие ветки остаются на своих местах.

Слияние объединяет изменения одной ветки с текущей веткой. При fast-forward Git может просто передвинуть указатель текущей ветки вперёд. Параметр --no-ff при слиянии отдельной ветки создаёт merge-коммит с двумя родителями, сохраняя в графе факт слияния.
