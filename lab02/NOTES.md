Рабочая папка - файлы на диске, которые я редактирую; git видит изменения, но не сохраняет их.

&#x20;Индекс (staging area) - промежуточная область, куда я добавляю изменения через git add. Это черновик будущего коммита.

&#x20;Коммит - зафиксированный снимок индекса в истории. У него есть хеш, автор, дата и сообщение.

Git - распределенная система контроля версий, работает локально на компьютере.

&#x20;GitHub - облачный сервис для хранения Git-репозиториев и совместной работы.

&#x20;Git - инструмент, GitHub - платформа.
